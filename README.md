# LeetCode Top Interview Questions

Repo luyện giải các bài LeetCode thường gặp trong phỏng vấn kỹ thuật. Các bài được sắp xếp theo độ khó và chủ đề để dễ tìm bài và ôn lại cách giải.

## Cấu trúc repo

| Thư mục | Nội dung |
| --- | --- |
| [Eazy](Eazy/) | Bài Easy theo chủ đề, gồm mảng, chuỗi, danh sách liên kết, cây, sắp xếp và tìm kiếm, quy hoạch động, thiết kế và toán. |
| [Medium](Medium/) | Dành cho bài Medium. Hiện chưa có lời giải. |
| [Hard](Hard/) | Dành cho bài Hard. Hiện chưa có lời giải. |

## Cách sử dụng

1. Chọn thư mục theo độ khó, rồi tìm bài theo chủ đề hoặc mã bài LeetCode.
2. Đọc `readme.md` trong thư mục bài để xem đề. Nếu bài có `note.md`, mở file đó để xem ghi chú về cách giải.
3. Mở thư mục ngôn ngữ tương ứng để xem lời giải bằng C++, Java hoặc Python tùy bài.
