# 387. First Unique Character in a String

[LeetCode problem](https://leetcode.com/problems/first-unique-character-in-a-string/)

Find the zero-based position of the earliest character that occurs exactly once in `s`. Return -1 if there is no such character.

## Example 1

```text
Input: s = "leetcode"
Output: 0
```

**Explanation:** The first character, l, occurs once.

## Example 2

```text
Input: s = "loveleetcode"
Output: 2
```

## Example 3

```text
Input: s = "aabb"
Output: -1
```

## Constraints

- `1 <= s.length <= 10^5`
- The string uses lowercase English letters.
