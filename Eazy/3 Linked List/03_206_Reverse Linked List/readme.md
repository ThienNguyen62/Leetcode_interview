# 206. Reverse Linked List

[LeetCode problem](https://leetcode.com/problems/reverse-linked-list/)

Reverse the links in a singly linked list and return the new head. An empty list stays empty.

## Example 1

```text
Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]
```

## Example 2

```text
Input: head = [1,2]
Output: [2,1]
```

## Example 3

```text
Input: head = []
Output: []
```

## Constraints

- The list contains 0 to 5000 nodes.
- `-5000 <= Node.val <= 5000`

## Follow-up

Can you implement both an iterative and a recursive reversal?
