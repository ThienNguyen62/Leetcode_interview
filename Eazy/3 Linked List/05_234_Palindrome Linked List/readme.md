# 234. Palindrome Linked List

[LeetCode problem](https://leetcode.com/problems/palindrome-linked-list/)

Return whether the sequence of values in the singly linked list is the same when read forward and backward.

## Example 1

```text
Input: head = [1,2,2,1]
Output: true
```

## Example 2

```text
Input: head = [1,2]
Output: false
```

## Constraints

- The list contains 1 to 10^5 nodes.
- `0 <= Node.val <= 9`

## Follow-up

Can you do this in O(n) time and O(1) auxiliary space?
