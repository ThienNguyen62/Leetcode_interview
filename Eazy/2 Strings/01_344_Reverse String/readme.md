# 344. Reverse String

[LeetCode problem](https://leetcode.com/problems/reverse-string/)

Reverse the character array `s` in place, using only constant auxiliary memory.

## Example 1

```text
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
```

## Example 2

```text
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
```

## Constraints

- `1 <= s.length <= 10^5`
- Every character is printable ASCII.
