# 242. Valid Anagram

[LeetCode problem](https://leetcode.com/problems/valid-anagram/)

Check whether `t` can be obtained by rearranging the characters of `s`. Each character must have the same multiplicity in both strings.

## Example 1

```text
Input: s = "anagram", t = "nagaram"
Output: true
```

## Example 2

```text
Input: s = "rat", t = "car"
Output: false
```

## Constraints

- `1 <= s.length, t.length <= 5 * 10^4`
- Both strings use lowercase English letters.
