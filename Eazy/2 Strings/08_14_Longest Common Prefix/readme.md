# 14. Longest Common Prefix

[LeetCode problem](https://leetcode.com/problems/longest-common-prefix/)

Return the longest initial substring shared by every string in `strs`. Use the empty string when there is no shared initial character.

## Example 1

```text
Input: strs = ["flower","flow","flight"]
Output: "fl"
```

## Example 2

```text
Input: strs = ["dog","racecar","car"]
Output: ""
```

**Explanation:** The first characters already differ.

## Constraints

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- Nonempty strings use lowercase English letters.
