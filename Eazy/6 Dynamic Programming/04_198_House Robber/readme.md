# 198. House Robber

[LeetCode problem](https://leetcode.com/problems/house-robber/)

Each entry in `nums` gives the money in a house along a street. Select houses to maximize the total without choosing any adjacent pair.

## Example 1

```text
Input: nums = [1,2,3,1]
Output: 4
```

Take the first and third houses.

## Example 2

```text
Input: nums = [2,7,9,3,1]
Output: 12
```

Take the first, third, and fifth houses.

## Constraints

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`
