# 70. Climbing Stairs

[LeetCode problem](https://leetcode.com/problems/climbing-stairs/)

Count the distinct sequences of steps that reach stair `n` from the ground when each move climbs either one or two stairs.

## Example 1

```text
Input: n = 2
Output: 2
```

The sequences are 1 + 1 and 2.

## Example 2

```text
Input: n = 3
Output: 3
```

The sequences are 1 + 1 + 1, 1 + 2, and 2 + 1.

## Constraints

- `1 <= n <= 45`
