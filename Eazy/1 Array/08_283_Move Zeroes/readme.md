# 283. Move Zeroes

[LeetCode problem](https://leetcode.com/problems/move-zeroes/)

Rearrange `nums` so that the zeroes come after every nonzero value. Preserve the order in which the nonzero values originally appeared. Modify the original array without allocating a copy.

## Example 1

```text
Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

## Example 2

```text
Input: nums = [0]
Output: [0]
```

## Constraints

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
