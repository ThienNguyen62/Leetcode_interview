# 102. Binary Tree Level Order Traversal

[LeetCode problem](https://leetcode.com/problems/binary-tree-level-order-traversal/)

Return the node values grouped by depth. List levels from top to bottom and values within each level from left to right.

## Example 1

```text
Input: root = [3,9,20,null,null,15,7]
Output: [[3],[9,20],[15,7]]
```

## Example 2

```text
Input: root = [1]
Output: [[1]]
```

## Example 3

```text
Input: root = []
Output: []
```

## Constraints

- The tree contains 0 to 2000 nodes.
- `-1000 <= Node.val <= 1000`
