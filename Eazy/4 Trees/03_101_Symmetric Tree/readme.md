# 101. Symmetric Tree

[LeetCode problem](https://leetcode.com/problems/symmetric-tree/)

Return whether the binary tree is a mirror image of itself across the root.

## Example 1

```text
Input: root = [1,2,2,3,4,4,3]
Output: true
```

## Example 2

```text
Input: root = [1,2,2,null,3,null,3]
Output: false
```

## Constraints

- The tree contains 1 to 1000 nodes.
- `-100 <= Node.val <= 100`

## Follow-up

Try both recursive and iterative symmetry checks.
